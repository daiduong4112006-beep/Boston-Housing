# Final Project: Boston Housing Analysis

This repository contains the completed Jupyter Notebook for the **Boston Housing** project (IBM Skills Network).

## Project Overview
The Boston Housing Dataset contains information collected by the U.S. Census Bureau concerning housing in the area of Boston, Massachusetts. 
The analysis focuses on descriptive statistics, data visualization, and hypothesis testing to explore relationships between housing prices and various demographic/environmental factors.

## Contents
- `FinalProject_Boston_Housing_Completed.ipynb`: The main notebook containing data exploration, visualizations, and statistical testing (T-test, ANOVA, Pearson correlation, and Regression analysis).

## Technologies Used
- Python 3
- Pandas, NumPy
- Matplotlib, Seaborn
- SciPy, Statsmodels
